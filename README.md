# Arman VPN — نسخهٔ سرور لینوکس

این fork فقط هستهٔ سرور لینوکس و وب‌پنل را نگه می‌دارد؛ برنامه‌های Android، Windows و macOS در این بسته نیستند. وب‌پنل صفحهٔ Locations را ارائه می‌کند و ورود وب و ورود از ترمینال هستهٔ upstream حفظ شده‌اند.

## نصب روی سرور

پس از قرار دادن این فایل‌ها در شاخهٔ `main` مخزن عمومی `arefhere51/arman-vpn` و انتشار اولین تگ نسخه (مثلاً `v1.0.19`)، GitHub Actions آرشیوهای لینوکس را می‌سازد. نصب آخرین انتشار:

```bash
curl -fsSL https://raw.githubusercontent.com/arefhere51/arman-vpn/main/install.sh | sudo bash
```

نصب‌کننده به Linux، systemd و curl نیاز دارد. برای دسترسی از بیرون، پورت پنل `10820` و پورت/پورت‌های پراکسی را در فایروال سیستم و ارائه‌دهنده باز کنید. پورت پنل و پورت پراکسی اصلی با loginهای جداگانه محافظت می‌شوند. نصب تازه رمزها را در خروجی ترمینال نشان می‌دهد؛ آن‌ها را امن نگه دارید.

## چند لوکیشن هم‌زمان

در پنل به `http://SERVER-IP:10820/app/#locations` بروید، وارد شوید و **Enable all locations** را بزنید تا کشورهایی که در فهرست سرور دریافت شده‌اند، به listenerهای مستقل افزوده شوند. پورت‌های جدید به‌طور خودکار از `20000` به بالا اختصاص می‌یابند. سپس در هر ردیف می‌توانید پورت را عوض کنید یا listener را خاموش/روشن کنید. ذخیرهٔ تغییر باعث راه‌اندازی مجدد موتورهای پراکسی می‌شود؛ فایل‌ها و حساب‌های Firefox دست‌نخورده می‌مانند.

هر پورت، پراکسی محلی SOCKS5/HTTP همان کشور را ارائه می‌دهد. موتورهای location از همان `AccountPool` daemon و همان حساب/مدیریت نشست Firefox استفاده می‌کنند؛ حساب یا flow ورود جداگانه‌ای برای هر کشور ساخته نمی‌شود. سهمیهٔ ماهانه نیز بین همهٔ اتصال‌ها و لوکیشن‌ها مشترک است. listener فقط وقتی روی سیستم فعال است که ستون وضعیت پنل آن را نشان دهد؛ برای دسترسی خارجی، همان پورت را در هر دو فایروال باز کنید.

پراکسی اصلی و انتخاب location اصلی موجود حفظ شده‌اند. پورت/کشورهای تکراری و برخورد با پورت پراکسی اصلی یا پنل رد می‌شوند. فعال‌سازی همهٔ کشورها به تازه و قابل‌دریافت بودن فهرست لوکیشن وابسته است.

## مدیریت از ترمینال

```bash
sudo arman-vpn status
sudo arman-vpn logs
sudo arman-vpn restart
sudo arman-vpn add-account
sudo arman-vpn list-accounts
sudo arman-vpn panel
```

ورود به Firefox Account از ترمینال (`sudo arman-vpn add-account`) یا پنل امکان‌پذیر است؛ پروتکل ورود تغییر نکرده است. به‌روزرسانی از آخرین GitHub Release:

```bash
sudo arman-vpn update
```

## ساخت محلی

Go `1.27.2` یا جدیدتر لازم است:

```bash
cd core && go test ./...
cd .. && bash scripts/build-linux-core.sh
```

آرشیوهای server در `dist/` ساخته می‌شوند (amd64، arm64 و armv7). انتشار نسخه با tag باید با فایل `VERSION` یکسان باشد؛ مثلاً مقدار `1.0.19` و tag برابر `v1.0.19`.

## نکتهٔ پروژه

این نرم‌افزار مستقل و غیررسمی است و وابستگی/تأیید رسمی Mozilla ندارد. پیش از استفاده، شرایط حساب Firefox و محدودیت‌های محل استفاده را بررسی کنید. این fork هیچ فایلی را در `mozvps` تغییر نداده است.
